# الاستوديو المجاني المحلي للفيديو

هذا المسار هو المعتمد بدل Agnes. لا يستدعي KIE أو أي مزود مدفوع لتوليد الفيديو أو الصور. إنشاء الفيديو محليًا لا يحتاج إلى مفتاح API؛ أما الرفع والإدارة في ImageKit فيحتاجان مفتاح ImageKit خاصًا محفوظًا محليًا فقط.

## كيف يعمل

1. يقرأ المشاهد ونص التعليق العربي من ملف JSON.
2. يبحث عن صورة مناسبة لكل مشهد عبر Wikimedia Commons، ويجرب كلمات بديلة وأوسع إذا لم يعثر البحث الأول على صورة مؤهلة.
3. يقبل فقط صورًا ذات رخصة قابلة لإعادة الاستخدام: CC0 أو Public Domain أو CC BY فقط (يتجاهل CC BY-SA وCC BY-NC وCC BY-ND). يتجاهل الملفات التي لا يستطيع التحقق من رخصتها.
4. ينشئ تعليقًا عربيًا عبر Edge TTS، ثم يركب الصور والصوت والترجمة والحركة البسيطة باستخدام FFmpeg على جهاز Windows.
5. يحفظ الفيديو وملفات نسب المصادر والتراخيص محليًا.
6. يرفعه إلى ImageKit بعد التأكد من أن حجمه لا يتجاوز 100MB، دون أي fallback مدفوع.
7. ينشئ `metricool-publish-package.json` يتضمن رابط الوسيط العام، وعنوان SEO، والوصف، والهاشتاغات، والوسوم، ومعلومات الإسناد، ليُستخدم في جدولة YouTube Shorts وFacebook Reels عبر Metricool.

**مهم:** الأولوية الآن للقطات فيديو حقيقية متحركة. الصور ليست إلا خيارًا احتياطيًا عند عدم العثور على مقطع مرخص مناسب. هذا ليس نموذج توليد اصطناعي من نص إلى فيديو. Edge TTS خدمة قراءة صوتية عبر الإنترنت بلا مفتاح API؛ تعتمد على توفر خدمة Microsoft وقد تتغير أو تتوقف. لا توجد رسوم أو أرصدة مدفوعة ضمن هذا المسار.

## متطلبات Windows

- Python 3.12 مع Python Launcher (`py.exe`).
- FFmpeg وFFprobe على PATH.
- اتصال بالإنترنت لتنزيل الصور وإنشاء الصوت.
- مساحة حرة لتنزيل الصور وحفظ MP4.

## اختيار الموضوع وبيانات SEO تلقائيًا

يمكن تشغيل مخطط الموضوعات المحلي قبل إنتاج الفيديو:

```powershell
.\scripts\run-free-video.ps1 -AutoTopic
```

يختار `scripts/topic_seo_planner.py` موضوعًا من كتالوج عربي مدمج (علوم وتقنية)، ويراعي سجل `media-output/topic-history.json` لاختيار الموضوع الأقل استخدامًا. ينشئ تلقائيًا ملف `auto-topic-project.json` يتضمن:
- افتتاحية تشد الانتباه وسيناريو من خمسة مشاهد.
- كلمات بحث إنجليزية وصيغ بديلة للعثور على صور مناسبة في Wikimedia Commons.
- الكلمة المفتاحية الرئيسية والكلمات المرتبطة وعنوان YouTube والوسوم والهاشتاغات.
- توضيحًا صريحًا لطريقة الاختيار.

يمكن تحديد المجال باستخدام `-TopicCategory science` أو `-TopicCategory technology`. الاختيار الحالي تحريري من كتالوج محلي، وليس قياسًا مباشرًا لحجم البحث أو ترندات لحظية؛ لا تُعرض هذه البيانات على أنها اتجاهات حية. لا يتطلب المخطط حزم Python إضافية أو API أو خدمة مدفوعة.

## التشغيل

1. افتح `examples/free-video-project.json` في VS Code.
2. غيّر العنوان ونص كل مشهد. اكتب كلمات البحث عن الصورة باللغة الإنجليزية، ويمكنك إضافة `fallback_search` كقائمة كلمات بديلة إذا كانت الصورة المطلوبة متخصصة.
3. شغّل PowerShell من مجلد المشروع ثم نفّذ:

```powershell
.\scripts\run-free-video.ps1
```

يمكن تحديد ملف مشروع مختلف:

```powershell
.\scripts\run-free-video.ps1 -SpecPath "C:\MergerMedia\my-video.json"
```

السكربت يستخدم Python 3.12 ويثبت حزمة `edge-tts` الصغيرة عند الحاجة فقط. لا يثبت PyTorch أو نماذج محلية ثقيلة.

## الملفات الناتجة

سيُنشأ مجلد بعنوان الفيديو داخل `media-output`، ويحتوي على:
- ملف MP4 النهائي.
- لقطات الفيديو أو الصور الاحتياطية والصوت والمقاطع المرحلية.
- `sources.json` بسجل ملفات Commons.
- `video-description-and-attribution.txt` بنص جاهز لوصف الفيديو مع أسماء المؤلفين والتراخيص وروابط المصدر.

يجب الاحتفاظ بنسب المصدر وإضافة بيانات الإسناد إلى وصف الفيديو عند النشر، خصوصًا لوسائط CC BY. راجع صفحة كل ملف إذا كانت هناك شروط إضافية.

## حدود التنفيذ

- الحد الأقصى 12 مشهدًا لكل فيديو.
- إخراج 720p، بمعدل 25 إطارًا في الثانية، وإعداد ترميز سريع لتقليل الضغط على المعالج.
- يعتمد نجاح توليد الصوت على اتصال الإنترنت وتوفر Edge TTS. عند تعذر الخدمة يتوقف التنفيذ برسالة واضحة ولا ينتقل إلى مزود مدفوع.
- يظل الفيديو الأصلي محفوظًا محليًا، ويُرفع أيضًا إلى ImageKit عند ضبط المفتاح. بعد الرفع ينتج ملف جاهز لجدولة Metricool؛ إنشاء الملف لا يعني أن المنشور جُدول أو نُشر بالفعل.

## إدارة مكتبة ImageKit من PowerShell

بعد ضبط المفتاح مرة واحدة عبر `scripts\\setup-imagekit.ps1`، يرفع المشغّل الفيديو تلقائيًا ويُنشئ حزمة النشر. ويمكن أيضًا إدارة المكتبة مباشرة دون وضع المفتاح في الأوامر أو الملفات:

```powershell
py -3.12 scripts\\imagekit_media_library.py list --path "/VYROX" --type all
py -3.12 scripts\\imagekit_media_library.py search 'name : "رحلة"'
py -3.12 scripts\\imagekit_media_library.py details FILE_ID
py -3.12 scripts\\imagekit_media_library.py update FILE_ID --tags "VYROX,Shorts,Arabic" --description "وصف الوسيط"
py -3.12 scripts\\imagekit_media_library.py copy "/VYROX/source.mp4" "/VYROX/Backup"
py -3.12 scripts\\imagekit_media_library.py move "/VYROX/old.mp4" "/VYROX/Archive"
py -3.12 scripts\\imagekit_media_library.py rename "/VYROX/old.mp4" "new-name.mp4"
py -3.12 scripts\\imagekit_media_library.py delete FILE_ID
```

**تنبيه:** الحذف نهائي ويزيل الملف وإصداراته من المكتبة. إعادة التسمية تغيّر رابط التسليم القديم؛ لذلك لا تستخدمها بعد نشر الرابط إلا بعد تحديث المنشورات والروابط. النقل يغيّر مسار الملف. يلزم مفتاح ImageKit خاص بصلاحية قراءة وكتابة لعمليات الإدارة، أما العرض والبحث فيكفيهما مفتاح قراءة. لا يُطبع المفتاح ولا يُحفظ في Git.

على الخطة المجانية، حد حجم ملف الفيديو الواحد 100MB؛ وتخضع عمليات الرفع والتخزين والتسليم لحدود الخطة الحالية. لا يتجاوز السكربت هذه الحدود ولا ينتقل تلقائيًا إلى خدمة مدفوعة.

### جدولة Metricool دون خطة مدفوعة

ملف `metricool-publish-package.json` هو حزمة جاهزة للجدولة، وليس تأكيدًا بأن المنشور أُنشئ. في خطة Metricool المجانية، يمكن استخدام Metricool MCP من ChatGPT لجدولة المنشورات ضمن حد الخطة (حتى 20 منشورًا شهريًا)، بينما REST API المباشر الذي يمكن تشغيله من سكربت محلي متاح فقط في خطتي Advanced وCustom. لذلك لا يطلب هذا المشروع ترقية مدفوعة أو API token مدفوعًا؛ يتم تمرير الحزمة إلى Metricool MCP عند تنفيذ النشر من ChatGPT. يجب التحقق من حالة كل منشور بعد الجدولة، وعدم تكرار إنشاء منشور سبق جدولته.
